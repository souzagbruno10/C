# C
A linguagem C a é base em que vários sistemas operacionais foram desenvolvidos, sistemas embarcados foram criados, assim como é fundamento de várias linguagens de programação de alto nível.
É o básico que todo programador deve ter como fundamento, não à toa é utilizada nos cursos universitários de Ciências da Computação no mundo todo. Este é um repositório pessoal de estudos, composto por exercícios que abordam os principais temas na linguagem C, desde os mais básicos e até os mais avançados.
